### 💰 Quanto Foi?

Aplicação web mobile-first desenvolvida para registrar e acompanhar gastos de forma rápida, simples e organizada.

O projeto permite registrar informações como valor, categoria, descrição, forma de pagamento, data, horário e classificação do gasto.
